02 / OBJECTIVE FEEDBACK

The reward comes from physics.

CONTINUOUS SIGNAL, STRICT SUCCESS

Progress earns credit.
Every constraint must pass.

s = max(0, 1 + log₁₀(r) / 3)
s = 1 when r ≥ 1
Minimum target
r = measured / target
Maximum target
r = target / measured
Design reward
mean(scores) + 0.5 if solved

Equality targets use a symmetric ratio with tolerance. Episode reward adds a separate bonus for saved steps, only after success.

No human labels.

No LLM judge.

The circuit either works
or it doesn’t.

Fales executes proposed designs in a simulator, then converts gain, bandwidth, phase margin and power into feedback for evaluation, reinforcement learning and trajectory generation.

07 / PROCEDURAL TASKS
